# Coding Agent GUI

Нативное desktop-приложение для взаимодействия с AI coding agent, похожее на Claude Code Desktop.

## Установка

```bash
pip install PyQt5
```

## Запуск

```bash
# Из корня проекта
python -m coding_agent.gui

# Или напрямую
python coding_agent/gui/agent_gui.py
```

## Возможности

- **Интерактивный чат**: Общение с агентом в реальном времени
- **Проводник файлов**: Просмотр структуры рабочего каталога
- **Быстрые команды**: Кнопки для частых действий (Plan, Scan, Clear, Retry)
- **Настройки**: Диалог конфигурации LLM endpoint и workspace
- **Меню инструментов**: Доступ ко всем функциям агента
- **Статус бар**: Отображение состояния агента

## Структура GUI

```
coding_agent/gui/
├── __init__.py          # Экспорт основного API
├── __main__.py          # Точка входа для запуска как модуля
└── agent_gui.py         # Основная реализация GUI
```

## Компоненты

### CodingAgentGUI
Главное окно приложения со всеми основными компонентами.

### FileExplorer
Виджет проводника файлов для навигации по рабочему каталогу.

### AgentWorker
Фоновый поток для выполнения задач агента без блокировки UI.

### SettingsDialog
Диалог настройки параметров подключения к LLM и рабочего каталога.

## Горячие клавиши

- `Ctrl+O` - Открыть workspace
- `Ctrl+L` - Очистить чат
- `Ctrl+R` - Повторить последнюю задачу
- `Ctrl+P` - Сгенерировать план
- `Ctrl+S` - Сканирование уязвимостей
- `Ctrl+,` - Настройки
- `Ctrl+Q` - Выход

## Требования

- Python 3.8+
- PyQt5>=5.15.0
- coding_agent (текущий проект)

## Пример использования

1. Запустите GUI: `python -m coding_agent.gui`
2. При необходимости настройте подключение к LLM в Settings
3. Введите запрос в поле ввода текста
4. Нажмите Enter или кнопку Send
5. Наблюдайте за выполнением задачи агентом
